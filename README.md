# 🌌 Planets Scroll Animation

An interactive 3D planets showcase built with **Three.js**, **GSAP**, and **Tailwind CSS**. This project presents an immersive scroll-based experience where each scroll rotates a group of textured planets and transitions between elegant headings.

## 🛠️ Tech Stack

- [Three.js](https://threejs.org/) – 3D rendering
- [GSAP](https://gsap.com/) – Smooth animations
- [Tailwind CSS](https://tailwindcss.com/) – Responsive utility-first styling
- [HDRI Environments](https://polyhaven.com/) – Realistic lighting
- Custom fonts – Bellina, Helvetica Now Display, Gilroy (ensure you load them if hosting)
